How it works

Every website starts with a question. Hero's Walls answers it first.

Before your devices load an ad, they look up its address through DNS. Hero's Walls sits in that step and refuses to answer for ad and tracker domains. No browser extension and nothing installed on your devices.

01

A device asks for an address

Your phone, laptop, or smart TV looks up a domain like ads.example.com before it attempts to fetch any content.

02

The chip checks its list

Hero's Walls compares the domain name against its memory blocklist using binary search and label-walking in under 1 ms.

03

Ads never load

Blocked domains receive an instant 0.0.0.0 sinkhole response. Legitimate queries are forwarded upstream and resolve normally.

Setup Guide

Four steps from a bare board to a blocked ad.

You'll need an ESP32-C3 board, a USB-C data cable, and the Arduino CLI with the official ESP32 board package installed.

STEP 1

Compile & Flash

Plug the ESP32 into your computer via USB. Run the compiler and upload commands. Replace COM9 with your board's serial port.

# Compile for ESP32-C3
arduino-cli compile --fqbn esp32:esp32:esp32c3:PartitionScheme=min_spiffs,FlashMode=dio,FlashFreq=80,CDCOnBoot=default .

# Flash to device over USB
arduino-cli upload -p COM9 --fqbn esp32:esp32:esp32c3:PartitionScheme=min_spiffs,FlashMode=dio,FlashFreq=80,CDCOnBoot=default .
STEP 2

Connect to Wi-Fi

On first boot, the ESP32 broadcasts its own Wi-Fi setup network. Join it on your phone or laptop, enter your home network details, and save.

1. Connect Wi-Fi  ESP32_AdBlocker
2. Open browser   http://192.168.4.1
3. Navigate to    Network Settings
4. Save           Enter home Wi-Fi SSID & Password
5. Ready          Device reboots & begins filtering!
STEP 3

Verify Filtering

Verify sinkhole operation directly from terminal. Blocked domains return 0.0.0.0; legitimate domains resolve cleanly.

# Should return 0.0.0.0 (Sinkholed!)
nslookup doubleclick.net <device-ip>

# Should resolve normally
nslookup google.com <device-ip>
STEP 4

Router DHCP Setup

Set the ESP32's IP as the primary DNS server in your router settings. Every device on your home network is now protected.

Core Features

Small hardware, careful engineering.

01

Sub-Millisecond Decisions

Binary search over on-chip sorted pointer arrays plus an LRU positive answer cache delivers sub-millisecond lookup speeds.

02

Zero False Positives

Strict label-boundary matching guarantees that blocking doubleclick.net will never accidentally sinkhole benign domains like notdoubleclick.net.

03

Subdomain Inheritance

Recursive label walking automatically strips parent labels left-to-right, ensuring all subdomains are blocked without bloating the list.

04

Allowlist Precedence

System infrastructure and user-defined allowlist rules always take absolute priority over blocklists and pattern filters.

05

Minimalist Dark Dashboard

Inspect live DNS query volumes, toggle adblocking, and manage custom rules over real-time WebSockets directly on the chip.

06

Instant Failsafe Recovery

If Wi-Fi drops, it spawns a SoftAP recovery portal. If a download fails, it automatically rolls back to the previous flash snapshot.
